# Tools

Tools adalah kumpulan fitur yang dapat digunakan untuk membantu pengguna menjalankan berbagai kebutuhan di dalam platform.

Dokumentasi ini menjelaskan struktur tools sekaligus memberikan contoh penggunaan **HTML**, **CSS**, dan **JavaScript**.

---

## Apa itu Tools?

Tools merupakan fitur yang dirancang untuk melakukan pekerjaan tertentu secara lebih mudah dan cepat.

Contohnya:

- HTML Formatter
- CSS Formatter
- JavaScript Formatter
- JSON Formatter
- Text Converter
- Image Tools
- Developer Tools

Setiap tool dapat memiliki input, proses, dan output yang berbeda.

---

## Struktur Tool

Secara umum sebuah tool memiliki tiga bagian utama:

1. **Input**
2. **Process**
3. **Output**
